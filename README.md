## blackjack.net

Console Blackjack written in C# / .NET 10.

![Blackjack](https://raw.githubusercontent.com/gdonald/blackjack.net/master/ss2.png)

![Blackjack](https://raw.githubusercontent.com/gdonald/blackjack.net/master/ss1.png)

### Build and Run

    dotnet run --project src/Blackjack

### Run Tests

    dotnet test

### Project Layout

- `src/Blackjack/` — console app
